# 로봇청소기 오도메트리 시뮬레이터

차동구동 로봇(로봇청소기)이 두 바퀴 엔코더 값만으로 자기 위치를 추정하는 과정(오도메트리)을 동역학 5장 강체 평면운동학 개념으로 보여주는 인터랙티브 시뮬레이터입니다.

**실행 링크**: https://kimm22658-ops.github.io/robot-odometry-simulator/

## 5장 개념 연결

| 단원 | 시뮬레이터에서의 역할 |
|---|---|
| 5.2 고정축 회전, 5.3 구름 조건 | 바퀴 속도 v = rω |
| 5.4 상대속도 | v_R = v_L + ω × r → ω = (v_R − v_L)/L, v_C = (v_L + v_R)/2 |
| 5.5 순간중심 | ICR은 바퀴 축 연장선 위, R = v_C/ω |
| 오도메트리 | Δs, Δθ를 적분해 위치 추정 (오일러 / 중점법 / 원호 적분) |

## 기능

- 주행 시나리오 8개: 지그재그 청소, 나선 청소, 8자 주행, 원 주행, 직진, 제자리 회전, 한쪽 바퀴 정지, 직접 입력
- 변수 설정: 바퀴 반지름, 바퀴 간격, 바퀴 각속도, 엔코더 노이즈, 바퀴 마모, 바퀴 간격 보정 오차, 미끄러짐, 적분 방법, 계산 주기
- 실제 경로 vs 추정 경로, 순간중심(ICR), 속도 벡터, 속도 분포선 표시
- 재생, 스텝 이동, 속도 조절, 시간 스크러버
- 매 순간 값이 대입된 계산 흐름 패널, 오차 그래프
